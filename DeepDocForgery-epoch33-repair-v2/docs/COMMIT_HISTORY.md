- `770e6f5` (6 October): converts saved Torch/CUDA/DataLoader RNG state to CPU byte tensors. This directly addresses the 5 October `RNG state must be a torch.ByteTensor` failure.
- `8ebb42b` (21 October): adds the non-finite-loss skip path. It leaves the previous `output`/`losses` graph referenced when `continue` bypasses backward. The same skip behaviour appears in 19 October logs, before this commit; local uncommitted edits and/or clock differences are plausible. There is insufficient evidence to select one explanation.
- `283bc64` (26 October): adds failure logs, not a training fix.
- `25f5fae`, `d7f8688`, `536c54e` (26 October): HPO artefact additions/removals, not a change addressing the live-graph problem.
- `fb677da` and `43b4e30`: status/log/run-instruction updates. Old status timestamps cannot override later epoch-completion/checkpoint events.
